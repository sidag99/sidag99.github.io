Projects

Code Mode: a sandbox for AI agents in AnythingMCP

Black Forest Hackathon, Oct 2026 · Team of five · Challenge set by KOCH Freiburg GmbH

AI agents that call business tools directly tend to pull whole tables into their context, which is slow, expensive and often leaks data the agent never needed. We built a sandbox for AnythingMCP, an open-source MCP gateway, that changes the pattern: the agent writes a short JavaScript script, the script runs next to the connectors in an isolated V8 sandbox, and only the final answer goes back to the model.

The sandbox calls tools with the user’s own permissions, refuses writes, has no network access or secrets, cannot reach other tenants, and stops runaway scripts.

My part: I broke down the challenge and decided with the team what to build, steered the build (much of the code was written with AI coding agents), and debugged and fixed the issues that came up on the way to a working demo.
